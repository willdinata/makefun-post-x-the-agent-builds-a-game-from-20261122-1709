# starpaws

starpaws is a tiny browser game where a cat astronaut dodges asteroids and catches stars, built by an AI agent from this single prompt:

> Build me a tiny browser game from one prompt: a cat astronaut dodging asteroids and catching stars

The video of the build and the game is the X post linked above. Will posted the video [on X](https://x.com/willstudiolab/status/2124917603558895705).

## Run

With Node.js 22, run from the repository root:

```sh
node main.ts
```

This copies `POST.json` into `MAKEFUN_OUTPUT_DIR` when set, or `/output` otherwise, creating the output directory if needed.
